# Browser Package Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the 1034 generated `browser_*.go` binding stubs and the hand-written DOM API wrappers out of the flat repo root into a new `browser/` package, without exporting any AST internals.

**Architecture:** Root `package client` gains one small exported type (`TypeMarker`) that generated types embed to satisfy the unexported-method-sealed `Type` interface across the package boundary. All 1034 existing `browser_*.go` files are mechanically rewritten in place (not regenerated — the source JSON data root is not available in this repo) via a one-off Go script, then moved to `browser/`. The hand-written `browser.go` DOM wrappers move too, rewritten to use only already-exported `client` API.

**Tech Stack:** Go 1.26 (`go.mod`: `github.com/nsatyasrikar/client`), stdlib only.

**Spec:** `docs/superpowers/specs/2026-09-09-browser-package-split-design.md`

## Global Constraints

- No behavior change to emitted TypeScript/JS output (spec: "Out of scope: Any behavior change to emitted TypeScript/JS output").
- No new exported symbols beyond `client.TypeMarker` (spec section 2).
- `cmd/clientgen -check` must still validate generated-file freshness after the change.
- Every commit must be immediately followed by `graphify update .` (per project CLAUDE.md rule, and this project's explicit ask to keep the graph current per commit) — the plan installs the post-commit hook in the last task so this becomes automatic.

### Task 3: Migrate the 1034 existing `browser_*.go` files into `browser/`

**Interfaces:**
- Consumes: `client.TypeMarker` (Task 1)
- Produces: 1034 files under `browser/`, each `package browser`, each `type XType struct{ client.TypeMarker }`

Every existing file has the identical two-statement shape (confirmed by inspection):
```go
// Code generated by clientgen; DO NOT EDIT.
package client

type ActionType struct{}
func (ActionType) clientType() {}
```
This is a uniform mechanical rewrite — per golang-refactoring guidance, generate a rewrite tool rather than hand-edit 1034 files.

- [ ] **Step 1: Write the migration script**

Create `/tmp/migrate_browser.go` (throwaway, not part of the repo):

```go
package main

import (
	"fmt"
	"go/format"
	"os"
	"path/filepath"
	"regexp"
)

var (
	typeLineRe = regexp.MustCompile(`type (\w+) struct\{\}\nfunc \(\w+\) clientType\(\) \{\}\n`)
)

func main() {
	root := "."
	entries, err := filepath.Glob(filepath.Join(root, "browser_*.go"))
	if err != nil {
		panic(err)
	}
	if err := os.MkdirAll("browser", 0755); err != nil {
		panic(err)
	}
	for _, path := range entries {
		src, err := os.ReadFile(path)
		if err != nil {
			panic(err)
		}
		m := typeLineRe.FindSubmatch(src)
		if m == nil {
			fmt.Fprintf(os.Stderr, "SKIP (no match): %s\n", path)
			continue
		}
		typeName := string(m[1])
		out := []byte(fmt.Sprintf(
			"// Code generated by clientgen; DO NOT EDIT.\npackage browser\n\nimport \"github.com/nsatyasrikar/client\"\n\ntype %s struct{ client.TypeMarker }\n",
			typeName,
		))
		formatted, err := format.Source(out)
		if err != nil {
			panic(fmt.Sprintf("%s: %v", path, err))
		}
		newPath := filepath.Join("browser", filepath.Base(path))
		if err := os.WriteFile(newPath, formatted, 0644); err != nil {
			panic(err)
		}
		if err := os.Remove(path); err != nil {
			panic(err)
		}
	}
	fmt.Println("migrated", len(entries), "files")
}
```

### Task 4: Move and rewrite `browser.go` (DOM API wrappers)

**Files:**
- Delete: `browser.go` (root)
- Create: `browser/browser.go`
- Test: `browser/browser_test.go` (new)

**Interfaces:**
- Consumes: `client.Property`, `client.CallValue`, `client.Assign`, `client.ExpressionStatement`, `client.UnsafeExpression`, `client.Value`, `client.StringType`, `client.Element`, `client.Nullable`, `client.Unknown`, `client.FunctionType`, `client.Statement` (all already exported in `expression.go`, `type.go`, `literal.go`)
- Produces: `browser.Document` (`documentAPI`), `browser.ElementAPI` (`elementAPI`) with methods `GetElementByID`, `SetTextContent`, `AddEventListener` — same method signatures as before, just on the `browser` package.

The original root `browser.go` (for reference, before this task deletes it):
```go
package client

type documentAPI struct{}

var Document documentAPI

type elementAPI struct{}

var ElementAPI elementAPI

type documentValue struct{}

func (documentAPI) GetElementByID(id Value[StringType]) Value[Nullable[Element]] {
	return wrap[Nullable[Element]](callExpr{propertyExpr{literalExpr{"document"}, "getElementById", false}, []expression{id.node}})
}
func (elementAPI) SetTextContent(el Value[Element], value Value[StringType]) Statement {
	return Assign(Property[Element, StringType](el, "textContent"), value)
}
func (elementAPI) AddEventListener(el Value[Element], name Value[StringType], callback Value[FunctionType]) Statement {
	return ExpressionStatement(wrap[Unknown](callExpr{propertyExpr{el.node, "addEventListener", false}, []expression{name.node, callback.node}}))
}
```

`SetTextContent` already uses only exported API — moves unchanged (just package + qualifier). `GetElementByID` and `AddEventListener` build `callExpr`/`propertyExpr` directly (unexported) — rewrite both using `client.Property` (to get `document.getElementById` / `el.addEventListener` as a property access) plus `client.CallValue` (to call it). `documentValue` (unused type, no references anywhere in the file or elsewhere — confirmed via grep) is dropped, not moved.

- [ ] **Step 3: Write `browser/browser.go`**

```go
package browser

import "github.com/nsatyasrikar/client"

type documentAPI struct{}

var Document documentAPI

type elementAPI struct{}

var ElementAPI elementAPI

func (documentAPI) GetElementByID(id client.Value[client.StringType]) client.Value[client.Nullable[client.Element]] {
	doc := client.UnsafeExpression("document")
	method := client.Property[client.Unknown, client.Unknown](doc, "getElementById")
	return client.CallValue[client.Unknown, client.Nullable[client.Element]](method, id)
}

func (elementAPI) SetTextContent(el client.Value[client.Element], value client.Value[client.StringType]) client.Statement {
	return client.Assign(client.Property[client.Element, client.StringType](el, "textContent"), value)
}

func (elementAPI) AddEventListener(el client.Value[client.Element], name client.Value[client.StringType], callback client.Value[client.FunctionType]) client.Statement {
	method := client.Property[client.Element, client.Unknown](el, "addEventListener")
	call := client.CallValue[client.Unknown, client.Unknown](method, name, callback)
	return client.ExpressionStatement(call)
}
```

`UnsafeExpression` wraps a raw code string (`rawExpr`); `Validate` flags `rawExpr` as a `SeverityWarning` diagnostic (`validate.go:47-48`), and `TypeScript()` only aborts on `SeverityError` (`emit.go:16-19`) and never returns diagnostics to the caller — so this produces the same output string and the same `nil` error as the original `literalExpr{"document"}` did, with no observable behavior change.
